# ПАРАМЕТРЫ HIGHS ДЛЯ ОПТИМИЗАЦИИ

## Обзор

Создано 2 скрипта для подбора параметров HiGHS:

1. **netlib_optimize.py** - умный последовательный подбор (greedy search)
2. **netlib_gridsearch.py** - полный перебор всех комбинаций (grid search)

---

## РАСШИРЕННОЕ ПРОСТРАНСТВО ПАРАМЕТРОВ

### Общие параметры (для всех солверов)

1. **presolve** - предварительная обработка
   - Варианты: `"off"`, `"choose"`, `"on"`
   - Дефолт: `"choose"`
   - Влияние: упрощает задачу перед решением
   - Комбинаций: 3

2. **parallel** - параллельное выполнение
   - Варианты: `"off"`, `"choose"`, `"on"`
   - Дефолт: `"choose"`
   - Влияние: использование многопоточности
   - Комбинаций: 3

**ИТОГО общих: 3 × 3 = 9 комбинаций**

---

### Параметры Simplex-метода

3. **simplex_strategy** - стратегия симплекс-метода
   - Варианты: 0, 1, 2, 3, 4
     - 0: Choose (автоматический выбор)
     - 1: Dual (serial) - двойственный последовательный
     - 2: Dual (SIP) - двойственный с SIP
     - 3: Dual (PAMI) - двойственный с PAMI
     - 4: Primal - прямой
   - Дефолт: 1
   - Влияние: определяет основной алгоритм
   - Комбинаций: 5

4. **simplex_scale_strategy** - стратегия масштабирования
   - Варианты: 0, 1, 2, 3, 4
     - 0: Off - без масштабирования
     - 1: Choose - автовыбор
     - 2: Equilibration (default) - уравновешивание
     - 3: Forced equilibration - принудительное
     - 4: Max value - по максимальному значению
   - Дефолт: 2
   - Влияние: численная устойчивость
   - Комбинаций: 5

5. **simplex_dual_edge_weight_strategy** - стратегия весов двойственных рёбер
   - Варианты: -1, 0, 1, 2
     - -1: Choose - автовыбор
     - 0: Dantzig - правило Данцига
     - 1: Devex - метод Devex
     - 2: Steepest Edge - наискорейший спуск
   - Дефолт: -1
   - Влияние: выбор входящей переменной
   - Комбинаций: 4

6. **simplex_primal_edge_weight_strategy** - стратегия весов прямых рёбер
   - Варианты: -1, 0, 1, 2
     - -1: Choose
     - 0: Dantzig
     - 1: Devex
     - 2: Steepest Edge
   - Дефолт: -1
   - Влияние: выбор входящей переменной для прямого симплекса
   - Комбинаций: 4

**ИТОГО для Simplex: 5 × 5 × 4 × 4 = 400 комбинаций**
**С общими: 400 × 9 = 3,600 комбинаций**

---

### Параметры IPM (Interior Point Method)

7. **run_crossover** - запуск кроссовера после IPM
   - Варианты: `"off"`, `"choose"`, `"on"`
   - Дефолт: `"on"`
   - Влияние: получение базисного решения после IPM
   - Комбинаций: 3

**ИТОГО для IPM/IPX: 3 × 9 = 27 комбинаций**

---

### Другие солверы (HiPO, PDLP)

Для HiPO и PDLP используются только общие параметры.

**ИТОГО для HiPO: 9 комбинаций**
**ИТОГО для PDLP: 9 комбинаций**

## ОЦЕНКА ВРЕМЕНИ ВЫПОЛНЕНИЯ

При 91 задаче в benchmarks и 70% на обучение = ~64 задачи для подбора:

- Время на 1 задачу: ~0.5-2 секунды (зависит от размера)
- Среднее время на конфигурацию: ~32-128 секунд
- **Полный grid search: 32 часа - 130 часов (1.3-5.4 дня)**

### Оптимизация:

1. **Умный подбор (netlib_optimize.py)**:
   - Последовательный greedy search
   - ~200-300 конфигураций
   - Время: 2-4 часа

2. **Полный перебор (netlib_gridsearch.py)**:
   - Grid search всех комбинаций
   - 3,672 конфигурации
   - Время: 1-5 дней
   - Можно ограничить по времени или количеству

---

## КАКИЕ ПАРАМЕТРЫ ВЛИЯЮТ НА ЧТО

### Скорость решения:
- `simplex_strategy` - самый важный
- `simplex_dual_edge_weight_strategy` - важен для сложных задач
- `presolve` - может сильно ускорить

### Параллелизм:
- `parallel` - использование нескольких ядер
- `threads` (не включён) - явное количество потоков

### Численная устойчивость:
- `simplex_scale_strategy` - масштабирование матрицы
- `primal_feasibility_tolerance` (не включён)
- `dual_feasibility_tolerance` (не включён)

### Точность решения:
- Все tolerance параметры (не включены, чтобы не снижать точность)

---

## НЕ ВКЛЮЧЕНЫ (но можно добавить)

Следующие параметры влияют на точность, поэтому не включены в автоподбор:

- `primal_feasibility_tolerance` (default: 1e-7)
- `dual_feasibility_tolerance` (default: 1e-7)
- `ipm_optimality_tolerance` (default: 1e-8)
- `small_matrix_value` (default: 1e-9)
- `time_limit` - лимит времени
- `simplex_iteration_limit` - лимит итераций
