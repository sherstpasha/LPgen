1. ОБЩИЕ (для всех солверов)
   
   presolve: ["off", "choose", "on"]
   • Предварительное упрощение задачи
   • Может сильно сократить размер задачи
   • "choose" - автоматический выбор
   
   parallel: ["off", "choose", "on"]
   • Многопоточное выполнение
   • Эффективно на многоядерных CPU
   • "choose" - автоматический выбор

2. SIMPLEX-СПЕЦИФИЧНЫЕ
   
   simplex_strategy: [0, 1, 2, 3, 4]
   • 0 = Choose (автовыбор)
   • 1 = Dual serial (двойственный последовательный) [DEFAULT]
   • 2 = Dual SIP (с SIP)
   • 3 = Dual PAMI (с PAMI)
   • 4 = Primal (прямой)
   
   simplex_scale_strategy: [0, 1, 2, 3, 4]
   • 0 = Off (без масштабирования)
   • 1 = Choose (автовыбор)
   • 2 = Equilibration [DEFAULT]
   • 3 = Forced equilibration
   • 4 = Max value
   
   simplex_dual_edge_weight_strategy: [-1, 0, 1, 2]
   • -1 = Choose (автовыбор) [DEFAULT]
   • 0 = Dantzig (правило Данцига)
   • 1 = Devex
   • 2 = Steepest Edge (наискорейший спуск)
   
   simplex_primal_edge_weight_strategy: [-1, 0, 1, 2]
   • Аналогично dual, но для прямого симплекса
   • -1 = Choose [DEFAULT]

3. IPM-СПЕЦИФИЧНЫЕ
   
   run_crossover: ["off", "choose", "on"]
   • Кроссовер для получения базисного решения
   • "on" [DEFAULT] - всегда выполнять
   • "off" - не выполнять (быстрее, но не базисное решение)
